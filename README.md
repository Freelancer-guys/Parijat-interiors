# Parijat Interiors (पारिजात Interiors)

> **Every space has a story. Let’s make yours beautiful.**

A luxury interior architecture and design website for **Parijat Interiors**, specializing in residential homes and modern commercial spaces across Maharashtra and India.

---

## 🌟 Features

- **Parijat Interiors Brand Identity:** High-resolution circular Devanagari logo with floral detail and "Design The Devine" submark.
- **Fixed Sticky Header:** Stays pinned at the top with frosted glass blur effect while scrolling through all sections.
- **Balanced Desktop Hero:** Two-column architectural composition with clamped serif typography and prominent calls to action.
- **Featured Commercial Portfolio (MYSA Derma Clinic):**
  - Interactive multi-image carousel showing actual clinic interior photography:
    - Doctor Consultation Suite & Wave Lighting Feature
    - Waiting Lounge & Illuminated 3D Brass Signage
    - Reception & Perspective Corridor with Profile Lighting
  - Lightbox inspection modal for high-resolution photo exploration.
  - Touch-swipe support on mobile and keyboard arrow navigation.
- **Curated Residential Portfolio:** Curated spaces including contemporary living lounges, private residences, and ergonomic kitchen architecture.
- **Architectural Services Grid:** 6 structured service cards (Residential, Commercial, Consultation, Full Home Execution, Modular Kitchens & Wardrobes, Turnkey Projects) filling the screen with balanced layout.
- **Compact Process Timeline:** 4 structured steps (Understand, Discuss, Design, Execute).
- **Authentic Craftsmanship Trust Section:** Direct focus on verified project execution with no fabricated reviews.
- **Enquiry Form & WhatsApp Channel:** Validated project enquiry form with clear feedback and floating WhatsApp feature prompt.
- **Fully Responsive & Accessible:** Fluid scaling across mobile (375px–414px), tablet (768px), and widescreen viewports (1440px+).

---

## 🚀 Tech Stack

- **Framework:** React 18 with TypeScript
- **Bundler:** Vite
- **Styling:** Vanilla CSS design system with curated luxury palette (Ivory `#faf7f0`, Indigo Blue `#173b88`, Warm Clay `#a58a70`)
- **Icons:** Lucide React
- **Deployment:** Vercel

---

## 📦 Local Development

1. **Install dependencies:**
   ```bash
   cd project
   npm install
   ```

2. **Run dev server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```

---

## 🌐 Deploying to Vercel

The project includes `vercel.json` configurations at both the root level and within `project/`.

1. Import this repository in [Vercel](https://vercel.com/new).
2. If Root Directory is left as default `./`, Vercel will automatically build `project` via the root configuration.
3. If setting Root Directory to `project`, Vercel will use Vite's standard output (`dist`).
4. Click **Deploy**.
